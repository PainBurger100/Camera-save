RAW? You’re in the right place.

CR2, CR3, NEF, ARW, RAF, DNG, ORF, RW2, PEF and more use the camera’s embedded preview, with RAW decoding as a fallback. JPEG, PNG, WebP, AVIF, GIF, BMP, HEIC/HEIF and TIFF are supported too. Camera and compression support can vary; unreadable files can be skipped.

Your originals stay yours.

Everything runs locally. Keep and pass only label photos. Originals are removed only when you review the passed list and confirm deletion. Delete passed shows the exact file list, then Windows asks you to confirm moving those originals to the Recycle Bin. The app has no permanent-delete fallback. Recycle support can vary by drive and provider. Changed files and symbolic links are skipped. Decisions save in the app; the latest folder reopens automatically.

Demo photos: exif-samples (github.com/ianare/exif-samples).
